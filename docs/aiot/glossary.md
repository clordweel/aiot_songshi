# 名词表（Glossary）

| 术语 | 含义 |
|------|------|
| **AIOT** | AI Operation Technology：基于大模型的 OT（运营技术），本仓库指用代理辅助运维与二开流程 |
| **PVE / Proxmox VE** | 虚拟化平台；业务机在 VM 中运行 |
| **bench** | Frappe 官方 CLI：`bench` 管理站点、应用、迁移、进程等 |
| **site** | Frappe 多站点中的单个站点（对应 `sites/<site_name>`） |
| **Frappe** | 应用框架；**ERPNext** / **HRMS** 为其上的应用 |
| **DocType** | Frappe 中数据模型与表单的元类型；REST API 常围绕 DocType |
| **二开** | 通过自定义 **app**（而非改核心）扩展功能 |
| **HumanPrimary** | 以人类阅读为主的文档（如培训）；默认不要让模型整库加载 |
| **Audit 简报** | 真实执行后的短记录，供人工审批与事后核查 |
