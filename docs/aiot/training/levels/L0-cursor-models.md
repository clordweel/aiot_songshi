# L0：按任务选择 Cursor 模型档位

> 以 Cursor 客户端**当前可选模型列表**为准；下文用**能力档位**描述，避免写死易过期的商品名。Pro 订阅下具体条目请在 **Settings → Models**（或当前版本等价入口）查看。

## 档位与典型任务

| 任务形状 | 建议档位 |
|----------|----------|
| 轻量问答、单文件小改、熟悉仓库 | **快速**或**均衡** |
| 计划迭代、目录/规则设计、长篇文档起草 | **均衡**；多方案权衡、安全与合规边界、复杂依赖时临时升到**旗舰**或**带加长推理**（若客户端提供） |
| 跨多文件重构、大二开补丁、疑难排错 | **旗舰**或标注为**长上下文**的模型 |
| 工具密集的 Agent（多终端/多次检索） | 在反馈速度可接受下选**稳定均衡**；若频繁遗漏约束再升档 |

## 使用习惯

- 先用均衡推进；**卡住或要终审方案**再切高档，可减少延迟与配额压力。
- 型号名会轮换：**档位 + 场景**是培训主干；可在文末尾自行维护「当期附录：客户端里各档位对应名称」并**季度或随 Cursor 大版本**更新。

## 与本项目的关系

- 日常 bench / API 任务：skills 在 `.cursor/skills/`；不必为执行任务而通读本培训目录。
