# Prompt：API 任务拆解（ERPNext / Frappe）

将自然语言业务需求拆成可执行步骤，再映射到 HTTP API。

1. **明确 DocType 与操作**：创建 / 更新 / 取消 / 提交 等；不确定则先查 meta。
2. **读 meta**：字段名、必选、选项、依赖；避免猜字段。
3. **权限与角色**：当前密钥/用户能否操作；失败时区分 403 与数据校验错误。
4. **幂等**：重复提交是否安全；是否需要先 `GET` 再 `PATCH`。
5. **写操作后验证**：再 `GET` 或列表查询确认状态。
6. **留痕**：若为真实环境写操作，事后在仓库根目录 `audits/` 按 `docs/aiot/AUDITS.md` 记简报。
